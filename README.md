# Conn3x for Scoop

Install Conn3x on Windows with [Scoop](https://scoop.sh):

```powershell
scoop bucket add conn3x https://github.com/conn3xorg/scoop-bucket
scoop install conn3x/conn3x
```

Update with `scoop update conn3x`. Each release refreshes the manifest here, checked against the release's checksums.

You can also install with Homebrew on macOS and Linux, or from the zip on the [releases page](https://github.com/conn3xorg/conn3x/releases). Docs live at [docs.conn3x.org](https://docs.conn3x.org).

Found a problem with the manifest? Open an issue on [conn3xorg/conn3x](https://github.com/conn3xorg/conn3x/issues).
